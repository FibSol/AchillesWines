# Addon Icons

Replace the following files before publishing this addon to a public repository:

- **icon.png** — 256×256 px PNG. Recommended: aubergine background (#1A0B2E) with coral wine glass icon (#FF5C8A). Used in the HA addon store card.
- **logo.png** — 256×256 px PNG. Same design guidelines. Used as the sidebar panel logo.

A source SVG is available at `../public/icons/icon.svg`. Run `scripts/gen-icons.sh` (requires ImageMagick or Inkscape) to rasterise it, then copy the output here and resize to 256×256.
